### [BotKit](https://github.com/jacksontoro60-arch/BotKit)

A modular discord.py bot kit with a setup wizard and a multi-client host
supervisor. The wizard writes each server's config and keeps the bot token in
`.env`. Each server runs only the features listed in that config.

Included features: scheduled announcements, Minecraft status alerts, message
translation, member verification, and moderation tools.
